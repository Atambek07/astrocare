# Data Provenance

AstroCare separates three provenance classes everywhere in the system.

---

## 1. Provenance classes

| Class | Meaning | Example |
| --- | --- | --- |
| `NASA_REAL` | Actual NASA/OSDR measurement or metadata. | CBC hemoglobin value from OSD-569. |
| `NASA_DERIVED` | Calculated from NASA records with a documented method. | Shannon diversity from OSD-572 species abundances. |
| `SYNTHETIC` | Generated by the AstroCare simulation engine. | 1-Hz HR/HRV telemetry for ASTRO-01. |

A value is never upgraded from one class to another.

---

## 2. Required provenance fields

For NASA evidence:

- `provenance_type`;
- `source_organization`;
- `source_repository`;
- `study_id`;
- `study_title`;
- `dataset_id`;
- `file_name`;
- `source_url`;
- `publication_reference`;
- `subject_id`;
- `biospecimen_id`;
- `original_measurement_name`;
- `original_value`;
- `original_unit`;
- `normalized_measurement_name`;
- `normalized_value`;
- `normalized_unit`;
- `transformation_method`;
- `processing_version`;
- `checksum`;
- `retrieval_timestamp`;
- `measurement_timestamp`;
- `timepoint`;
- `quality_status`;
- `limitations`.

For synthetic records:

- `simulation_engine_version`;
- `model_version`;
- `random_seed`;
- `scenario_id`;
- `parameter_profile_id`;
- `mission_timestamp`;
- `generation_timestamp`.

---

## 3. Examples

### NASA_REAL

```json
{
  "provenance_type": "NASA_REAL",
  "study_id": "OSD-569",
  "original_measurement_name": "ANALYTE",
  "original_value": "4.7",
  "original_unit": "10^3/uL",
  "quality_status": "VALID"
}
```

### NASA_DERIVED

```json
{
  "provenance_type": "NASA_DERIVED",
  "study_id": "OSD-572",
  "measurement_name": "Shannon diversity",
  "transformation_method": "shannon_diversity_from_species_relative_abundance"
}
```

### SYNTHETIC

```json
{
  "provenance_type": "SYNTHETIC",
  "simulation_engine_version": "astralis-simulation-1.0.0",
  "model_version": "astralis-hybrid-physiology-1.0.0",
  "random_seed": 20260501,
  "scenario_id": "HYPERCAPNIC_CABIN"
}
```

---

## 4. Frontend display

The frontend shows provenance in the Data Sources view and labels simulation telemetry as `SYNTHETIC`.

It never presents mock or simulation output as live NASA measurements.
